# Chlorophyll

Chlorophyll is a work-in-progress SDK for Plants vs. Zombies: Garden Warfare 2.

This SDK was initially generated by Icelin, an in-development framework for dumping Frostbite engine `TypeInfo` into C++ types.
Icelin will be made publicly open-source at a later date.

A few of the non-reflected types have been implemented, but the goal is to eventually implement everything. In the meantime, critical types (such as `TypeInfo`) are available.
